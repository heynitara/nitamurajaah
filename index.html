Cara memakai fitur game dan database cloud.

🎮 Cara Main Sambung Ayat

  1. Klik Main atau tombol ▶ Mulai.
  2. Baca ayat yang ditampilkan, lalu pilih ayat selanjutnya dari 4 pilihan.
  3. Benar → dapat XP + koin + combo. Salah → nyawa berkurang.
  4. Pakai Petunjuk (10 koin) untuk mengaburkan 1 jawaban salah.
  5. Selesaikan 10 soal atau sampai nyawa habis.

☁️ Simpan Progres ke Cloud

  1. Buka tab ☁️ Cloud.
  2. Isi Nama (min. 2 huruf) dan PIN (min. 3 karakter).
  3. Klik Simpan ke Cloud — progres (XP, koin, streak, dll) tersimpan di Google Sheets.
  4. Di HP/browser lain: isi nama + PIN yang sama → Ambil dari Cloud.

Jangan bagikan PIN. Siapa yang punya nama+PIN bisa restore akun itu.

🏆 Leaderboard

Ranking global berdasarkan total XP. Tekan Refresh di tab Cloud untuk melihat peringkat terbaru. Main & simpan ke cloud agar namamu muncul.

💌 Kirim Saran

Di tab Cloud, tulis permintaan surah atau saran fitur, lalu kirim. Admin bisa melihatnya di panel Admin.

📊 Statistik & Badge

Tab Statistik menampilkan level, akurasi, streak terbaik, dan badge. Badge terbuka otomatis saat syarat terpenuhi (mis. 100 XP, 5 game, dll).

🔐 Panel Admin (pemilik situs)

  1. Deploy Apps Script dulu (lihat SETUP-GOOGLE.md).
  2. Klik menu 🔐 Admin → masukkan password admin saja.
  3. Kelola user & feedback (lihat, edit, hapus, buat baru).
