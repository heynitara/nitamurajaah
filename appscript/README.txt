NITA MURAJAAH — PAKET THUMBNAIL LINK

Isi:
- thumbnail.jpg: foto yang kamu kirim, untuk dipakai sebagai gambar preview.
- open-graph-tags.html: kode metadata preview untuk WhatsApp dan media sosial.

CARA PASANG (penting agar website/game yang sudah ada tidak terhapus):
1. Buka repositori GitHub yang menerbitkan https://heynitara.github.io/nitamurajaah/.
2. Unggah file thumbnail.jpg ke folder utama (root) repositori. Pastikan alamat ini bisa dibuka: https://heynitara.github.io/nitamurajaah/thumbnail.jpg
3. Buka index.html website yang sudah ada, lalu salin tag di open-graph-tags.html ke dalam bagian <head> ... </head>.
4. Simpan/commit perubahan dan tunggu GitHub Pages menerbitkannya.
5. Kirim link https://heynitara.github.io/nitamurajaah/ ke WhatsApp. Preview dapat tertunda karena cache WhatsApp.

JANGAN mengganti seluruh index.html website yang sekarang dengan file kode tag saja, karena bisa menghapus game/fitur yang ada.
Catatan: preview tidak bisa dipasang hanya dengan membuat ZIP; file perlu diunggah dan metadata ditambahkan ke website live.
